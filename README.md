# EVA Recording Manager

Windows app that records EVA game sessions (Game = Streamlabs, Camera = OBS), matches them to EVA Admin bookings, uploads to Drive and emails the links.

- `app/` – application source (current version in `app/version.txt`)
- `tests/` – automated tests (run with Python 3.12)
- `tools/` – release builders
- `latest.json` – what the app reads for updates (version, package URL, SHA-256)

The installer and update ZIP are published under **Releases** (they are larger than GitHub allows in the repository).
